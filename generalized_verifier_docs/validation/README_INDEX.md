# Validation Proof Index

One line per proof artifact in this directory. Everything listed was
produced by real execution on this machine (see each doc for transcripts).

## Per-verifier validation (original proof docs)

- `VALIDATION.md` — verifiers 01 / 03 / 04: structural gate, two-stage
  build (CE vs LE), differential semantic gate; recorded-failure corpus +
  reference zero-false-positive sweep (`run_validation.sh` reproduces).
- `VALIDATION_05.md` — verifier 05 response-integrity: EMPTY / LOOP /
  TRUNCATED / OK calibrated against recorded degenerate generations
  (`05/run_validation_05.sh`).
- `VALIDATION_06.md` — verifier 06 candidate-boundary: FORBIDDEN_FILE /
  DUPLICATE_FILE / OMITTED_FILLED / TRUNCATED_LISTING vs the production
  parser, incl. agreement sweep (`06/run_validation_06.sh`).
- `VALIDATION_07.md` — verifier 07 warning-hygiene classifier: 13 g++
  diagnostic classes with actionable fix hints (`07/run_validation.sh`).

## Three-control self-validation (this layer)

- `SELF_CHECK.md` — the 6x3 matrix (positive / fault / tamper) with real
  pasted outputs; generated by `self_check.py` (host run).
- `self_check.py` — orchestrator; zero task names, drives the six verifier
  CLIs and their `--receipt` emitters.
- `self_check_cases.json` — the case matrix as data (inputs, expectations,
  tamper rationale).
- `run_all.sh` — host entry point: `bash generalized_verifier_docs/validation/run_all.sh`.
- `self_check_results.json` — machine-readable host-run results.
- `self_check_receipts/<case-id>/` — one kernel receipt per case (18 total).
- `self_check_generated/` — runtime-generated tamper inputs
  (unclosed-fence truncation, mixed build log).

## Sandbox execution proof (Docker)

- `run_sandboxed.sh` — runs the whole self-check suite inside
  `glm47-strange-multi-env:gcc13.3-v2` with launcher-mirroring controls
  (network none, read-only root, tmpfs /tmp, caps dropped, non-root user).
- `sandbox_run_receipt.json` — the end-to-end sandbox receipt: image id,
  controls, per-case kernel verdicts, sha256 of all inputs/outputs.
- `sandbox_out/` — raw container artifacts (per-case receipts,
  `SELF_CHECK.sandbox.md`, results JSON).

## Receipt emitter

- `../receipt_compat.py` — shared stdlib-only module wrapping any of the
  six verifiers' verdicts into the sandbox runner's kernel-receipt JSON
  shape (`--receipt DIR` on each verifier).
